# Canonical delimited tables

CSV/TSV records now enter one ordered `CanonicalDelimitedTable` before output format selection. Each column has an `id` (`c1`, `c2`, …), original or generated `label`, and `origin`. Identifiers follow ordinal position and cannot collide with source labels. Record `index`, `fieldCount`, and `cells` retain source order and width. A `null` cell beyond `fieldCount` is missing; an explicit `""` is present and empty. The widest record synthesizes additional columns without dropping excess fields. `rowWidthMismatch`, `duplicateHeader`, and `blankHeader` remain applied import diagnostics.

CSV/TSV JSON schema `2.0` replaces the old `content.tables` presentation and header-key `content.data` projection. `content.canonicalTable` is the source of truth. `content.data` is an ID-keyed record array derived from it, with the same values and `null` for missing fields. Migration from CSV/TSV `1.1`/`1.2`: read labels from `content.canonicalTable.columns`, values in record order from `records[].cells`, and use `data[].cN` only after mapping each ID to its column. A consumer that used `data[].<header label>` must switch to column IDs. Non-delimited schema `1.1` is unchanged. Application version remains `1.0.0` during this unreleased phase.

Markdown emits static headings and one JSON code block for columns and each record, with record ordinal and raw field count. Code blocks use a fence longer than any run of tildes in the encoded value. Literal HTML angle brackets and ampersands are JSON Unicode-escaped; JSON decoding recovers exact source text, including leading/trailing spaces, CRLF inside fields, literal formulas, pipes, links, and blank values. The column list binds cell IDs to original labels. `null` and `""` have distinct meanings. No row is padded to the width of another cell. The independent 2,000-data-record amplification fixture produced under 1 MB without dropping records in the native P03 test.

Existing Markdown code blocks and ordered lists from other converters remain on the shared formatter path. Its generic table renderer also stopped computing maximum-cell widths. The committed CSV fixtures were regenerated and reviewed for identical data values under the new representation. P08 reran the complete Debug/Release native matrix, validators, signed IDE Product Build/Test/Run, and sandbox inspection after the later phases; the source-bound record is in `P08_COMPLETION.md` and external gate evidence.
