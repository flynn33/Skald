# Extraction completeness and migration

The P05 output contract records each PDF page or image frame with its 1-based identity, extraction source (`native`, `visionOCR`, or `none`), status (`complete`, `empty`, or `partial`), OCR confidence when available, and warnings. Document summary status and aggregate warnings distinguish an empty page from failed extraction. A locked PDF fails with `passwordRequired`; no normal output is published. PDF native text is kept when usable, and only pages without usable text are rasterized for Vision OCR. Repeated meaningful text is retained. PDF pages are limited to 64, OCR rasters to 2,048 pixels per dimension and four million pixels, and images to 64 frames and 40 million source pixels per frame. The default Vision recognizer accepts an optional language list; low average confidence below 0.6 marks a page or frame partial.

XML JSON moves from the older name-grouped projection to schema `2.0`: `content.data.$xml` holds one root node with `name`, `namespaceURI`, `attributes`, and an ordered `content` array of `text`, `cdata`, and `element` entries. Empty and absent text remain distinct. Whitespace, CDATA, repeated child names, and namespace identity survive in source order. Markdown carries the same ordered tree in a recoverable JSON block. Input is limited to 16 MiB, 10,000 nodes, depth 64, and 8 MiB of text. DTDs and entities are denied before parsing; XMLParser external resolution is disabled.

HTML extraction uses a resource-free tag subset and strict UTF-8, capped at 8 MiB. Tags with attributes or resource-bearing elements fail with `externalResourceDenied` before extraction. The installed Xcode 26.6/macOS 26.5 SDK lacks the newer asynchronous NSAttributedString HTML loader; offscreen WebKit also timed out in the signed sandbox because its WebContent process requested network permission. Rather than grant Skald a broad network capability, a bounded Foundation tag/entity parser now processes accepted in-memory markup on the coordinator's detached background task, with cancellation and a deadline. An independent unsandboxed local TCP listener test observed zero requests from an attempted image reference; the signed IDE test cannot host the listener under its existing network-denying sandbox and verifies the preflight denial. HTML text is projected as plain blocks. Table structure is currently unextracted and marked partial. WebArchive inputs fail explicitly until a resource-isolated reader exists.

RTF, RTFD, DOC, DOCX, and ODT continue through the non-HTML NSAttributedString importer. Detected attachments and text-table blocks are marked partial. DOC/DOCX/ODT are also marked `containerStructuresNotVerified`, because the text importer alone cannot prove every embedded object survived. Representative RTF, DOCX, and ODT native fixtures verify visible text and truthful outcome status. This warning is a coverage limit, not a claim that all variants have been qualified.

The application version remains `1.0.0` (Xcode build `1`). PDF, image, and XML readable JSON schemas are now `2.0`; CSV/TSV already uses `2.0`. These are output-document schema versions, independent of the application release number.
