# P08 review record

The package's four review prompts were run as distinct direct reviews of the initial checkout through P08, including the workflow, native tests, fixtures, and current uncommitted files. The `/review` interface was unavailable in this session; this is the direct-review fallback specified by the package, not a claim of an external review service. Final run artifacts and per-file hashes are recorded in the separate gate ledger and completion report.

## Behavior and architecture

The native `FolderSelectionService` returns selected URLs to `ConversionViewModel`; `SkaldAppModuleView` exposes the picker, drop, format, and CSV controls. The view model starts one detached conversion task and passes selected options to `ConversionManager`. Its lock rejects overlapping runs; the manager snapshots sources, probes content, dispatches to the production converter registry, bounds output, and calls `OutputWriter.publish`. The published URL and truthful converted/partial/empty/skipped/failed counts reach `ConversionReportView`. The test target imports the same compiled Skald target; named-format tests also route through the real manager. No second parser or test-only production path was found. The signed IDE and Release UI exercised that route.

## Data integrity

The 34 CSV oracle entries bind independently specified logical rows/errors to fixture SHA-256 hashes, and the native seeded test checks 1,000 cases at five chunk sizes. Canonical-table tests compare exact expected records against JSON cells, ID-keyed projection, and recoverable Markdown blocks, including duplicate/blank labels, missing versus empty cells, embedded delimiters and newlines, leading zeros, and literal markup. The workbook positive tests assert physical sheet order, sparse coordinates, source numeric lexemes, formula text versus unverified caches, dates, and merged ranges; the fixture files were separately identified as XLSX, CFB/BIFF8 XLS, ODS, and ZIP by macOS `file`. PDF/XML/TIFF tests assert page/frame and mixed-content order. Expected values are stated in the tests and corpus contract rather than generated by the production parser.

The review found that an XLS worksheet without EOF could consume the next physical sheet's records when its own coordinates did not collide. `BIFF8WorkbookReader` now limits every worksheet to the following `BoundSheet8` offset and requires its EOF in that substream. A real CFB/BIFF8 negative fixture places a second-sheet cell at a noncolliding coordinate and confirms an `invalidXLS` failure with no published artifact. Repeated concatenation in `ContainerXMLNode.text` also copied accumulated text at every segment; joining collected segments preserves their order with bounded copying.

## Writer, security, and concurrency

`OutputWriter` opens the chosen target with `O_DIRECTORY|O_NOFOLLOW`, creates an owned same-directory temporary file with `O_EXCL`, handles short writes and EINTR, flushes and closes it, checks directory identity, and publishes with `renameatx_np(RENAME_EXCL)`. It removes only its own temporary inode on failure. Native tests cover occupied files/links, competing publishers, cancellation before and after commit, changed target identity, unsupported rename capability, permissions, and cleanup. `SourceWorklistBuilder` rejects links/special files and excludes a nested target; scoped access is held through the manager run and stopped in `defer`. ZIP member validation precedes owned temporary routing and aggregate publication; XML/HTML resource references are rejected, and workbook formulas are data rather than executable instructions.

The signed Xcode console exposed source paths despite private OSLog interpolation. `ConversionManager` now logs only inspection text or public failure stage/code; a fresh signed Debug IDE run and signed Release default log showed no source path for the denied HTML fixture. The picker action and segmented output selection also caused SwiftUI to warn about state publication during a view update. Scheduling both mutations on the next main-actor turn removed that warning in isolated picker, format, and full document-batch IDE runs. The workspace now scrolls vertically when a report exceeds its window. Xcode still prints negative-geometry diagnostics at window launch and after reports; the signed window displayed all controls and completed the exercised conversions, so that diagnostic remains an observed IDE rendering limitation rather than an asserted clean console.
